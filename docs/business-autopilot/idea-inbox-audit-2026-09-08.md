## 5. Rules to add to the inbox so this does not recur

1. **Intake freeze.** No new seed is scored until five finished products have 30 days of sales data. Seeds still get captured (name + original seed only), decision blank.
2. **Finished beats scored.** Any row whose asset already exists outranks any unbuilt row regardless of score. Add a column `Asset exists (Y/N)` and sort on it first.
3. **Outreach-dependent = QUEUE at best.** A row cannot be TEST FIRST or ACTIVE if its first milestone requires Danielle to send, call, or DM. Async-sellable only.
4. **Dated milestones expire.** Any milestone with a date or a "within N days" clock auto-flags for review when it passes. Eleven silently expired this month.
5. **One canonical row per buyer.** Same buyer, same credential, same channel → one row with tiers, not five rows.
6. **Seasonal rows carry a hard cutoff date** in the milestone (Elf: listing live by Oct 1 for November search; Halloween POD: Aug 15 for 2027).
